# 📂 Data Directory

This folder contains the datasets used for the Executive Sales & Growth Intelligence Dashboard.

## 🧹 Data Cleaning & Preprocessing
The raw dataset was cleaned and preprocessed using a custom **Python script** (utilizing the `pandas` library) to ensure data integrity and high quality before building the Power BI models. 
* **Data Cleaning Steps Performed:**
  * Removed duplicate rows and entries.
  * Cleaned and trimmed whitespace from column names and text fields.
  * Handled missing values and standardized data types for seamless aggregation in Power BI.

## 📊 Dataset Summary
* **Total Transactions / Orders:** ~19K rows of sales and order details.
* **Customer Base:** ~4K unique customers.
* **Key Metrics Tracked:** Transaction timestamps, order values, product return values, and geographical market distributions.
